## 3. 与旧页的有意差异

1. **分配详情从「仅 hover」改为「hover + 点击 + 键盘」**：浮层触发器是同 `<button>`，带 `aria-expanded`；打开抽屉时强制关闭浮层，避免浮层压住抽屉。
2. **`findListAssign` 由逐行串行改为 `Promise.all` 并发**：条数不变，减少往返；单条失败只把该行置空，不拖垮整页。
3. **选择用户时把「已分配教师」也置为已选**：旧页只传本次勾选列表，导致可以重复选中同一教师再由提交时去重拦截；新页在选择阶段就禁用，去重校验仍保留作兜底。
4. **删未提交行按 `teacherId` 对齐**：旧页按同下标同步 `toBeSelectList`，先删中间行会错位。
5. **抽屉布局重排**：旧页用 `a-row/a-col` + `label-col=6` 混排，标签与控件不对齐；新页改四列网格（教师 / 班级 / 类型 / 操作），教学-协作说明收进 `a-alert`。
