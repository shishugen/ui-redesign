## 3. 关键修复（旧页 / 迁移引入）

- `examManager/detail/review/index.vue`：
  - `JSON.parse` 包 `try/catch`，避免 AI 流式返回非 JSON 时整页崩溃；
  - 局部 `let message` 遮蔽 import 的 `message` 已改名 `promptText`；
  - `resize` 监听在 `onUnmounted` 移除，消除泄漏。
- `components/AiGradeDetail.vue`：
  - 模板内 `t('第 {n} 空：{text}', {...})` 触发 Vue 模板表达式解析器误报（与字符 `：` 组合时），已将带参 `t()` 抽到脚本方法 `fillBlankLabel(b)` / `partialFillLabel(detail)`，模板改为调用；`vite build` 由失败转为通过。
