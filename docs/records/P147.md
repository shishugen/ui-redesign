## 4. 与旧页的有意偏差（3 项，逐条可回退）

| # | 偏差 | 旧页实际行为 | 新页做法 | 理由 / 回退方式 |
| --- | --- | --- | --- | --- |
| 1 | 章节节点回调 | `ChapterViewItem` 点击叶子节点调 `props.callBackLearnChapter(...)`，但该 prop **从未声明** → 点击即 `TypeError` | 补 `callBackLearnChapter: Function, default: () => {}`，并 `?.()` 调用 | 旧页是运行时报错死代码；新页补默认值后点击不报错、行为仍为空操作。若要严格复刻报错，删掉该 prop 声明即可（不建议） |
| 2 | 列表 key | 子节点 `:key="child.id"`（章节对象无 `id` 字段，全为 `undefined`） | 改 `:key="child.chapterId"` | 旧 key 重复会导致复用错乱；纯前端缺陷修正，无接口影响 |
| 3 | 开始实验 | 确认弹窗 → 拼好 `{courseId, chapterId, userId, scheduleType:2, minutes}` → **函数体结束，无接口调用** | 确认后调 `saveScheduleByParams`（F1 已有同名方法，参数一一对应），成功 `message.success('实验已开始')` | 旧页是半截代码。若需回退为纯提示：删掉 `await saveScheduleByParams(...)` 一行即可 |

> 另有两处无语义影响的清理：`ConfigFlag` 去掉 `findListConfig` 调用（结果从未被使用，白跑一次请求）；`ChapterViewItem` 的 `leftWidth` 保留 prop 但不再参与宽度计算（改 CSS `min-width:0 + ellipsis`，去掉逐实例 `clientWidth` 读取）。
