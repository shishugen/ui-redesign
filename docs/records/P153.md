## 4. 有意偏差与旧页 bug 修复

| # | 旧页行为 | 新页做法 | 理由 / 回退 |
| --- | --- | --- | --- |
| 1 | `dateTimeRangePicker` **直接 mutate `props.scheduleDates`**，靠 4 个 `callback*` 函数 prop 回传；`default: []`/`{}` 非工厂函数 | 改为纯受控组件 + 7 个标准 `emits`（`date-change` / `range-change` / `add-range` / `remove-range` / `end-range` / `copy-day` / `remove-day`），父组件改自己的数组；`default` 改工厂函数 | 单向数据流；父子同批重写，无外部调用方。若需恢复旧契约，按旧 props 名包装一层 adapter 即可 |
| 2 | `minuteStep=1` → 生成 **1,440** 个时间 option | 父传 `:minute-step="5"`（288 项） | 旧页 1,440 项渲染开销大；5 分钟粒度满足排课。若要分钟级精度，把 `5` 改回 `1` |
| 3 | `modeMap[x].text` / `imageSourceMap[x].text` **无 `?.` 兜底** → 未知值直接崩 | 全部 `stateOf/typeOf/modeOf/sourceOf` 兜底返回「未知」 | 后端脏数据不白屏 |
| 4 | 单时段校验把 `"YYYY-MM-DD HH:mm"` 喂给只认 `HH:mm` 的 `timeToMinutes` → `NaN`，比较恒 false，**起止校验形同虚设** | 改用 `new Date(end) <= new Date(begin)` 比较 | 真实拦住结束早于开始 |
| 5 | 重叠检测只比前一个 `endMin`（未取历史最大）；间隔检测用**未排序**数组，乱序录入误判 | 统一用排序后的 `sorted` + `maxEnd` 历史最大值 | 乱序时段不误判、真重叠不漏 |
| 6 | `onMounted` 里 `clearInterval(trainingTimer)` 引用**未声明变量** → 潜在 ReferenceError；`onUnmounted` 只清 `userTimer`，30s 定时与 resize 监听泄漏 | 删除死引用；`onUnmounted` 清 `refreshTimer` / `userTimer` / resize 监听；资源抽屉另清 15s 定时与 3s 延时刷新 | 0 console error 实证 |
| 7 | `proxy.$modal`（主页约 25 处、抽屉 3 处） | antd `message` / `Modal.confirm` | 同语义 |
| 8 | `proxy.$refs.queryRef?.resetFields()` | 显式重建 `queryParams` 对象 | 不依赖旧插件 |
| 9 | 资源抽屉 `getStatus` 错误分支写 `statusObj.style='red'`，模板读 `.color` → 错误态无颜色；`status.toString()` 遇 null 崩 | 改用 `color` 字段 + `status == null` 兜底 | 错误态可见 |
| 10 | `imageSourceMap.notebook.value='volcano'`（值应为 `notebook`）；`config.container` 空引用 | 修正为 `notebook`；所有映射带兜底 | 数据正确 |
| 11 | 资源抽屉 `initConfigAndUser` catch 空吞异常且 `loading` 卡死；容器详情 popover 与「更多」hover-only | 加 `loadError` 错误态 + 重试；popover 改 `trigger="click"` 的 `<button>`，更多改 `a-dropdown` | 四态齐全、键盘可达 |
| 12 | `handleToCourse` `window.open('/online/learning?...')`（B03 未迁移路由，会 404） | `message.info('在线学习将在后续批次迁移')` | **D20 缺口诚实**：不跳 404、不开空白页，登记 §9 |
| 13 | 死代码：`timeOptions`、`getCourseConfig`、`addTimeRange`/`removeTimeRange`、未用图标、`console.log('提交数据'/'配额')` | 全部删除 | 无功能损失 |
| 14 | 硬编码色 `#4caf50` / `#ff4d4f` / `#419fff` / `rgb(239,241,246)` 等 | 全部改 v4 token | §3.4 宪法 |
| 15 | `formatDurationHour` / `formatDateAndTime` / `formatTimePeriod` 来自 F2 冻结层，返回中文 | 原样调用，不改冻结层 | 中文侧与旧页一致；英文侧这三个函数的输出仍为中文，属**已知边界**（见 §7） |

## 7. 遗留 / 待确认

- **真实后端未接**：排课、时段、额度、容器、用户均由本地桩返回。
- **F2 中文输出**：`formatDurationHour` 等 3 个冻结层函数返回中文（「4小时」「2026-11-20 08:00 ~ 12:00」），英文界面仍显示中文。属冻结层零改动边界，需产品确认是否在展示层做二次转换；用户确认前不动 F2。
- **D20 仍剩 `/online/learning`**：课程名点击进入在线学习走 `message.info` 提示（B03 域），未跳 404。
- **D25（本批登记）**：`utils/tokenChecker.js` 在冻结层清单标 `ADAPTER` 但新项目无此文件；旧页仅死导入 `startTokenCheck`，本批已删。若后续页面确实需要 30 分钟 token 过期轮询，需按 A 适配层同名新写（依赖 `utils/auth.js` / `utils/token.js` / `stores/session`），当前不做。
- **D26（本批登记）**：`Pagination` 公共组件默认页长为 `[12,24,36,48,60]`，本页 `queryParams.pageSize=10`（沿用旧页）。与 D23 同源，用户确认前不改公共组件默认值。
- **30s 自动刷新**：CDP 长断言期间可能触发额外 `listPlus` 请求，桩数据一致，不影响断言。
