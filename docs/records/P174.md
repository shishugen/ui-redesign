## 4. 有意偏差与旧页 bug 修复

| # | 旧页行为 | 新页做法 | 理由 |
| --- | --- | --- | --- |
| 1 | 答题页 `mainHeightSize = clientHeight - 40` + 固定定位头部 | 改 flex 撑满、头部与内容各自滚动 | 与第十六批同源：像素高度在缩放/多屏下必错位 |
| 2 | 看板左栏用 `a-layout-sider` + `float` | 改 flex + 原生按钮 | 键盘可达；不再依赖 antd 布局的包裹层滚动 |
| 3 | 章节筛选靠 `watch(chapterId)` 触发，但 `onCourseChange` 里又手动 `loadBoard()` | 保持两条触发路径，但 `onCourseChange` 里先 `loadFilters` 再 `loadBoard`，避免用旧章节打新课程 | 换课时序正确 |
| 4 | `checkPermi` 判权限（空权限会 console.error） | `getUserPermissions()` | 保证 0 console error |
| 5 | 学生清单接口失败时 `rows` 与 loading 一起空转，看不出是「没作业」还是「挂了」 | 补 `loadError` + 重试 | 四态齐全 |
| 6 | 看板 `loadBoard` 的 `catch` 无处理，异常后 loading 卡死 | 补错误文案写入 `emptyReason` + `finally` 释放 loading | 旧页会白屏 |
| 7 | 答题页 `gradeOpen` 标题在待批时只改文案，抽屉里其实空白 | 保留文案并前置说明（同旧页语义），不造假数据 | 服务端闸门行为不变 |
| 8 | 硬编码色（`#4b4b50` / `#dbe9f2` / `#f6ffed` / `#e6f7ff` 等） | 全部 v4 token；深色头部保留深色（`#1F2937`） | §3.4 宪法 |
| 9 | 选项 `a\b\c\d` 并列挤成一行 | 明确 `flex-wrap: nowrap` + 文字区 `flex:1` | 长选项不换行错位 |
