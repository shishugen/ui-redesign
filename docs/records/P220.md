## 4. 有意偏差与旧页 bug 修复

| # | 旧页行为 | 新页做法 | 理由 / 回退 |
| --- | --- | --- | --- |
| 1 | `mainHeight = clientHeight - 45` + `position:absolute` 固定高度，`a-layout-content` 写死 `height` | 改 flex 撑满 + 各面板内部滚动 | 旧写法改窗口尺寸即错位；新写法无像素计算，实测 `learn.offsetHeight == innerHeight` 且外层 `scrollHeight` 不超出 |
| 2 | `onMounted` 只读一次 `route.query` | 改 `watch(route.query)` + 面板 `:key` | **实测旧写法换课程不刷新**：去掉 `courseId` 后仍显示上一门课（本批 CDP 抓到并修掉） |
| 3 | 章节搜索只判断本节点，父级折叠时嵌套章节搜到了也看不见 | 命中判断递归到子树，且搜索即展开 | 旧页搜不到二级章节；新页实测「列表」命中可见 2 个节点 |
| 4 | 章节附件分组只遍历**顶层**章节，二级章节的附件永远不出现在左侧 | `initChapterFileData` 递归下钻 | 旧页丢了二级章节的附件/视频；新页实测「章节」分组出现 |
| 5 | `getReadTimeSecond` 正则多转义一层（`/\\s/`、`/\[^\\u4e00...]/`）→ 实际只匹配字面反斜杠 | 改 `/\\s/g` + `/[^\\u4e00-\\u9fa5a-zA-Z0-9]/g` | 旧页把空格标点全算进字数，阅读时长偏高；修正后按纯文本计 |
| 6 | `CourseFileItem` 的 `hasChildren` 读 `props.chapter.children`（该 prop 根本不存在） | 删死代码 | 只在模板外定义、从未求值，属隐藏地雷 |
| 7 | 拖拽条 `z-index: 2000/9999`，折叠按钮 `9999` | 全部降到 `z-index: 5`（页面内元素） | 旧值会盖住 antd 抽屉/弹窗（同 P153 记录的坑） |
| 8 | 拖拽条 `mousedown` 才能用，键盘不可达 | `role="separator"` + `tabindex=0` + ←/→ 键 | 无障碍要求；CDP 实测 300→324px |
| 9 | 章节 / 附件的行都是 `div @click` | 改原生 `<button>` + `aria-current` / `aria-expanded` | 键盘可达 |
| 10 | `CourseTraining` 里 `getStatus` 错误分支写 `statusObj.style='red'`，模板读 `.cls` | 统一返回 `{cls,title}` | 错误态有颜色 |
| 11 | `CourseTraining` 的 `moment` 依赖 + `delPaper` / `getContainer` / `startTokenCheck` 死导入 | 换 dayjs；死导入删；D 组要求的两个保留并注释 | 见 §1.1 |
| 12 | 硬编码色 `#19518b` / `#eff1f6` / `#ecf5ff` / `#70adcc` / `#2d3a6d` 等 | 全部 v4 token | §3.4 宪法 |
| 13 | 课程简介面板根节点是 `linear-gradient` 紫蓝大背景 + 卡片浮层 | 改白卡 + 浅灰底 | 视觉宪法；信息层级不变 |
