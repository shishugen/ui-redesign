## 1. 为什么是孤儿页（已确认）

全库检索旧项目 `ui/src`，对 `CourseTraining` 只有 **1 处命中**，且是 `ChapterList.vue` 里的注释：

```bash
$ grep -rn "CourseTraining" ui/src
ui/src/views/training/online/learning/items/ChapterList.vue:1011: ...同目录 CourseTraining.vue 早已用的 999...
```

- `ui/src/router/index.js` 无该组件引用；
- 后端 125 条菜单里没有对应 component（`training/online/learning/items/CourseTraining` 不在 `components` 列表内）；
- 页面壳 `learning/index.vue` 的 5 个 Tab 也不含「班级实验」，只 import 了 CourseInfo / ChapterList / CourseAttachments / CoursewareList。

结论：**旧系统里没有任何用户路径能打开它**。它的能力（按班级开实验、批量创建/释放学生容器资源）与第十四批已迁移的「排课计划 P153」重叠。

## 2. 处置与理由

| 选项 | 说明 | 采用 |
| --- | --- | --- |
| A. 不迁移 | 少 1,777 行死代码维护成本 | ✗ 违反「功能不丢 / 同名同路径」硬约束 |
| B. 迁移但不给入口 | 路径齐全、能力在，等等谁来接 | ✓ **本批采用** |
| C. 迁移并新增 Tab 入口 | 改变旧页信息架构，属于新增功能 | ✗ 不擅自加 |

因此：按旧页完整重写（919 行，较旧页 1,777 行压缩 48%，主要是样式与重复弹窗骨架），状态记 `implemented` —— 与「`done` 必须有 CDP 证据」的口径一致。
