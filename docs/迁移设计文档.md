只用 `src/theme.js` 的 `palette` 与 `design-system.scss` 的 `--*` 变量，禁止硬编码色值。页面骨架统一：`PageHead` + `PanelCard` + `StatCard` + `SourceBadge`，表格用 antd `Table` 的 v4 token（紧凑表头、无斑马纹、行悬停）。设计基准见 `design/aigc-ui-v2-proposal.html` 与 `.design-shots/`。

**列表页不设页头条**（2026-11-14 第十批拍板）：不再出现「状态圆点 + 标题 + 共 N 条记录 + 刷新」这一条独立横条。
理由：标题与面包屑已由 Layout 顶栏承担，条数在分页条里已有，重复且占首屏高度。
列表页**不放刷新按钮**（2026-11-14 第十一批）：进页面即拉取，搜索/重置本身会触发重查，工具条只保留筛选 + 主操作。

**迁移页贴顶**：经菜单进入（`/module/:key`）时，`ModuleView` 给根节点加 `page--flush`，把 `.page` 的 `22px 26px` 内边距清零（只留 20px 底部），避免顶栏与内容之间出现双重留白；静态路由本身没有 `.page`，两种入口视觉一致。

**详情/编辑页顶部紧凑**（2026-11-14 用户反馈）：这类页面根节点**不套 `.page`**，自带 `padding: 8px 18px 24px` + `gap: 12px`。原因：`.page` 的 `22px 26px` 与全局 `.page > * + * { margin-top: 16px }` 会和页面自己的 flex `gap` 叠加，实测返回条到首卡片 **32px**、顶部一大条空白；去掉后只剩 12px。返回条用 `width: fit-content`，不占满整行。

**壳页禁止固定高度裁剪**：列表壳页（课程/案例 × 管理端/实训端）不得写 `height: 100%; overflow: hidden` —— 内容超一屏会被裁掉，而主滚动容器 `.shell__main` 高度不变，表现为「滚动条滚不动」。改 `min-height: 100%`，让内容自然撑开由主容器滚动。

**滚轮兜底**：Layout 真正的滚动容器是 `.shell__main`，鼠标停在顶栏 / 左栏时滚轮默认不滚主内容。在 `.shell` 上以 `passive:false` 捕获 `wheel`，仅当事件目标不在任何「自身可滚动」的容器内时把 `deltaY` 转发给主容器；侧栏、下拉、内嵌滚动区保持浏览器默认行为。

## 6. 单页迁移 SOP

1. 从 `pages.csv` 取一行 `Pxxx`，记录 `old_path` → `new_path`（同名）。
2. 打开旧页，抄出**功能点清单**：接口方法、按钮/动作、表单字段、表格列、弹窗/抽屉、权限指令、状态（空/错/加载）、特殊交互（上传/播放/终端/交卷）。
3. 在新项目按 `new_path` 新建 `.vue`，用 v4 token 重写模板与样式；业务代码只调用 `F1` 里的原方法名，不改签名。
4. 补路由：静态路由照抄旧 `path/name/meta`；动态菜单由 `loadView(component)` 自动命中。
5. 跑 `node scripts/verify-migration.mjs`，确认该页 6 项对比无红项。
6. 写记录卡 `docs/records/Pxxx.md`，贴新旧截图（存 `.design-shots/migrated/`）。
7. 更新 `pages.csv` 的 `status=done` + `done_date` + `record`，并在 `docs/PROGRESS.md` 追加一行。**没有记录卡不得标 done。**

### 每页必答的 6 项对比

| # | 项 | 判定 |
| --- | --- | --- |
| 1 | 路径/命名 | 新文件路径 == 旧路径；无大驼峰改名 |
| 2 | 接口集合 | 旧页 import 的 api 方法名 ⊆ 新页；`apis.csv` 哈希未变 |
| 3 | 功能点 | 功能点清单逐项打勾，缺一项即不通过 |
| 4 | 权限 | `v-hasPermi` / `checkPermi` 字符串与旧页一致 |
| 5 | 状态 | 加载 / 空 / 错误 / 无权限四态都有，且数据不造假（接口没返回显示「—」） |
| 6 | 视觉 | 只用 v4 token；1440 / 1280 两档宽度无溢出 |

## 8. 进度记录机制（长期执行）

### 8.1 三个载体

| 载体 | 作用 | 谁改 |
| --- | --- | --- |
| `docs/inventory/pages.csv` | 唯一状态源：`status` / `done_date` / `record` 三列 | 每页完成时改 |
| `docs/records/Pxxx.md` | 单页记录卡：6 项对比结果、截图、遗留问题、验收人 | 每页新建 |
| `docs/PROGRESS.md` | 人读总台账 + 批次汇总 + 变更日志 | 每页追加一行 |

### 8.2 状态机

```
pending → in_progress → implemented → verified → done
                            ↓ 失败
                        blocked（必须写原因 + 关联待确认项）
```

`implemented_renamed` / `implemented_same` 是 B01 已有页面的初始状态，走完 6 项对比后才可转 `done`。

### 8.3 记录卡模板

见 `docs/records/_TEMPLATE.md`。固定字段：页面 ID、旧/新路径、批次、完成日期、执行人、6 项对比表、接口方法清单、功能点勾选、截图路径、遗留问题、结论。

### 8.4 强制规则

1. 一次只推进一个 `Pxxx`，不批量标 done。
2. 记录卡、`pages.csv`、`PROGRESS.md` 三者同步更新，缺一视为未完成。
3. 发现需要改接口或改旧 js → 一律记 `blocked`，写进 D 系列待确认，**不私自改**。
4. 每批结束跑一次 `verify-migration.mjs`，把 `COMPARE.md` 归档为 `docs/compare/COMPARE-<批次>-<日期>.md`。
5. §6.1 收口通道是唯一允许跳过「备份 / 源码盘点」、并把台账从 7 件压到 4 件的情形；压缩不得转移到「跳过校验」——build、`--strict` 两项、CDP 实跑四项缺一即未完成。

## 11. 中英切换（i18n）

> 本节记录的是**项目功能**（界面语言切换），不是文档翻译。状态：**已实现 + 已实跑验证**（2026-11-14）。

### 11.1 需求

项目需提交「中文 / English」切换：顶栏与独立页面可切换，切换后不刷新页面、不重发接口请求，刷新浏览器后保持选择。

### 11.2 方案（已确认，零依赖）

| 决策 | 做法 | 理由 |
| --- | --- | --- |
| 不装 `vue-i18n` | 自写 `src/i18n/index.js` | 只需两套静态文案 + antd locale；`package.json` 零改动，构建不受安装环节影响 |
| 中文原文即词条 key | `t('欢迎回来')`；zh-CN 时原样返回 | 中文侧不必再维护一份字典，新增中文文案不会出现「忘了登记 key → 空白」；缺译自动回退中文，不会白屏 |
| 响应式 | 模块级 `reactive` locale + `computed` | 模板、`computed`、Pinia getter 里调用 `t()` 会自动跟随切换；**不用 `:key=locale` 强制重挂载**，所以不会重新拉接口、不会丢表单输入 |
| 带占位符 | `t('共 {n} 条记录', { n: total })` | 数字型文案不拆成碎片，英文语序可独立调整 |
| 持久化 | `localStorage['aigc_locale']`，默认 `zh-CN` | **不跟随浏览器语言**：中文为默认，英文由用户主动选，避免评审机器系统语言把界面带走 |
| 组件库联动 | `App.vue` 的 `a-config-provider :locale` 在 `zh_CN` / `en_US` 间切 | 分页「条/页」、日期、空态、确认框等 antd 内置文案一起切 |
| 页面元信息 | `<html lang>`、`data-locale`、`document.title` | 便于样式、辅助技术与自动化断言 |
